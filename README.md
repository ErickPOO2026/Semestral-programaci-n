 Descripción
Este proyecto es una aplicación de consola en Java que automatiza la gestión operativa de una biblioteca académica. Permite el registro de ejemplares y usuarios, el procesamiento de préstamos y devoluciones con control de mora, el cálculo de penalizaciones y la emisión de reportes estadísticos.# Semestral-programaci-n
